## In plain words

Hephaestus is a desktop application that does everything popular “PDF websites”
do — merging, splitting, compressing, converting, signing, protecting — **but
entirely on your own computer.**

That single difference matters:

| | Online PDF websites | Hephaestus |
|---|---|---|
| Where your documents go | Uploaded to someone else’s server | **Nowhere — they never leave your machine** |
| Accounts, logins, e-mails | Usually required | **None** |
| Daily limits / paywalls | Common | **None — unlimited use** |
| Works without internet | No | **Yes** |
| Confidential documents (contracts, medical, financial) | Uploaded at your own risk | **Handled safely in-house** |

If your organization handles sensitive paperwork, Hephaestus removes the
“should we really be uploading this?” question entirely.

## What you can do with it

Twenty-two tools, grouped the way you think about the work:

### 📚 Put documents together & rearrange them
- **Merge PDF** — combine several PDFs into one, in the order you choose
- **Split PDF** — cut a document into pieces, single pages, or page ranges
- **Organize PDF** — see every page as a thumbnail; drag to reorder, rotate,
  duplicate or remove pages (like shuffling sheets on a desk)
- **Rotate PDF** — fix sideways or upside-down scans
- **Page Numbers** — add “Page 3 of 12” style numbering, where and how you like
- **Watermark** — stamp text (e.g. *CONFIDENTIAL*, *DRAFT*) or a logo across pages

### ⚙️ Make files smaller & fix problems
- **Compress PDF** — shrink heavy PDFs so they e-mail and upload easily
- **Repair PDF** — attempt to rescue a damaged or partly downloaded file
- **OCR PDF** — turn scanned paper into a PDF whose text you can search and copy

### 📥 Bring other files into PDF
- **Word → PDF**, **PowerPoint → PDF**, **Excel → PDF**
- **Images → PDF** — bind JPG/PNG pictures into one tidy document
- **HTML → PDF** — save a web page as a clean PDF

### 📤 Take PDF content out into other formats
- **PDF → Word**, **PDF → PowerPoint**, **PDF → Excel**
- **PDF → JPG / PNG** — every page as a picture, at print quality if needed
- **PDF → PDF/A** — the archival standard libraries and registries require

### 🔐 Protect, unlock & sign
- **Protect PDF** — add a password and control printing/copying/editing
- **Unlock PDF** — remove a password from a document you own
- **Sign PDF** — draw your signature with the mouse, type it, or import an
  image of it — then stamp it onto any page, exactly where you click

### ✏️ Touch-ups
- **Edit PDF** — add text notes and images (stamps, logos, seals) to any page

## Getting it on your computer

**Most people receive Hephaestus as a ready-made folder from their IT team or
colleague.** Nothing is “installed” in the system — the app lives in its own
folder and can sit on your Desktop, a USB stick, or a shared drive.

1. Obtain the folder named **`Hephaestus`** (as a ZIP or a copy).
2. Open it and double-click the application:
   - **Windows:** `Hephaestus.exe` (inside the `Hephaestus` folder you received)
   - **macOS:** `Hephaestus.app`
   - **Linux:** `Hephaestus`
3. The workshop opens. That’s it — no account, no internet, no setup wizard.

> **First launch on Windows?** If SmartScreen asks about an unrecognized app,
> choose *More info → Run anyway*, or ask IT to whitelist the folder.

### Two optional free helpers (only for some tools)

Most tools work the moment you open the app. Two of them rely on free,
well-known open-source engines that may or may not already be on your computer:

| If you want to… | Hephaestus uses | One-time install (ask IT if unsure) |
|---|---|---|
| Convert Word / PowerPoint / Excel / HTML, or export PDF/A | **LibreOffice** (free office suite) | [libreoffice.org](https://www.libreoffice.org/download/download/) |
| Make scanned PDFs searchable (OCR) | **Tesseract** (free OCR engine) | Windows: [installer](https://github.com/UB-Mannheim/tesseract/wiki) · Mac: `brew install tesseract` · Linux: `sudo apt install tesseract-ocr` |

You don’t need to decide now: if a tool needs a missing helper, Hephaestus
shows a friendly note inside that tool explaining exactly what to install, and
the **About & Diagnostics** screen (top-right of the home screen) always shows
what is ready on your machine.

## Your first task in 60 seconds

Let’s merge two PDFs — the pattern is the same for every tool:

1. **Open Hephaestus.** You land on *The Forge Floor*: a shelf of cards, one per
   tool. (Typing in *Seek a tool* at the top filters them.)
2. **Click “Merge PDF”.**
3. **Add your files** — click the dashed box and pick them, drop them from a
   folder, or press **Ctrl+V** after copying them. They appear in a list; use
   *Move ▲ / ▼* to set the order.
4. **Press the red “⚒ Forge” button.** A progress bar runs while the work happens.
5. **Done.** A message confirms the new file, and you can open its folder with
   one click. Your originals are untouched — results are always written as new
   files.

Every other tool follows the same rhythm: *choose files → set options → Forge*.

### Recipes people ask for

| “I need to…” | Use | Notes |
|---|---|---|
| Send one file instead of five | **Merge PDF** | Order the list before forging |
| E-mail a 40 MB scan | **Compress PDF** | *Recommended* level is the sweet spot |
| Sign a contract from home | **Sign PDF** | Draw once, stamp on as many pages as needed |
| Mark every page of a draft | **Watermark** | *Diagonal* or *Tile* across the sheet |
| Number a board pack | **Page Numbers** | Format is editable, e.g. `Page {p} of {n}` |
| Fix pages that came out sideways | **Rotate PDF** | Or rotate individual pages in **Organize** |
| Delete pages 4–7 of a scan | **Organize PDF** | Select the thumbnails, press *✕ Delete* |
| Search inside a 1998 fax scan | **OCR PDF** | Needs the free Tesseract helper |
| Give finance an Excel of a table | **PDF to Excel** | Needs the free LibreOffice helper |
| Archive a record permanently | **PDF to PDF/A** | Choose *PDF/A-2b* unless told otherwise |

## Privacy & security, stated plainly

- **Nothing is uploaded, ever.** There is no network code in the application;
  it can be run on a fully offline machine.
- **Your originals are never modified.** Every result is a brand-new file; the
  source documents stay exactly as they were.
- **Passwords protect, never harvest.** *Protect PDF* encrypts with modern
  AES-256. *Unlock PDF* only works when you supply the correct password of a
  document you own — the app contains no password-cracking capability.
- **Signatures stay yours.** Drawn signatures are processed in memory and
  written only into the PDF you save.

## Questions & troubleshooting

**Where do finished files go?**
Next to your originals by default; each tool also lets you pick any output
folder before you press Forge.

**Can I work on many files at once?**
Yes — merging, image-binding and all “convert to PDF” tools accept whole
batches; you can even drop an entire folder onto the selection box.

**The tool shows an amber note about LibreOffice or Tesseract.**
That tool needs the corresponding free helper (table above). Install it,
restart Hephaestus, and the note disappears. All other tools are unaffected.

**A PDF won’t open.**
It may be damaged or password-protected. Try **Unlock PDF** (if it’s yours and
you know the password) or **Repair PDF** first, then reopen the result.

**Drag-and-drop from Windows Explorer doesn’t work.**
Native dragging is enabled when the optional `tkinterdnd2` component is
present; otherwise use click-to-browse or Ctrl+V — equally fast.

**Will it slow my computer?**
Work runs in the background thread with a progress bar; large OCR jobs are the
heaviest task and simply take a few minutes on big scans.

### Requirements
- Python 3.10+ with Tkinter (`python3-tk` on Debian/Ubuntu; bundled with
  Python installers on Windows/macOS)
- `pip install -r requirements.txt` → PyMuPDF, pypdf, Pillow, pytesseract,
  cryptography
- Optional runtime engines: LibreOffice (headless), Tesseract; optional
  `tkinterdnd2` for native drag & drop

### Run & test
```bash
python -m hephaestus            # launch the GUI
python tests/test_engine.py     # 24 engine tests (merge/split/compress/
                                # rotate/watermark/protect/OCR-paths/registry)
```

### Build standalone executables
| OS | Command | Artifact |
|---|---|---|
| Windows | `packaging\build_windows.bat` | `dist\Hephaestus\Hephaestus.exe` |
| macOS | `./packaging/build_macos.sh` | `dist/Hephaestus.app` |
| Linux | `./packaging/build_linux.sh` | `dist/Hephaestus/Hephaestus` |

All three wrap `packaging/Hephaestus.spec` (PyInstaller, windowed, wax-seal
icon, assets bundled under `_internal/assets`).

### Architecture at a glance
```
hephaestus/
├── app.py            main window, home grid, navigation, diagnostics
├── theme.py          parchment/oxblood palette, Times New Roman stack
├── icons.py          vector canvas icons + wax-seal logo (no binary assets)
├── widgets.py        scroll frames, cards, drop zone, file list, footer
├── tools.py          declarative registry: 22 ToolSpecs drive the whole UI
├── engine/           pdf_ops · image_ops · ocr (Tesseract) · office (LibreOffice)
└── views/            tool_panel (generated UI) · organize · sign · edit
```
Processing is threaded (UI never blocks); every engine function reports
`(fraction, message)` progress. The generic `ToolPanel` builds a complete tool
UI from a `ToolSpec`; the three interactive tools (Organize, Sign, Edit) ship
bespoke views. UI is Tkinter/ttk with a serif archival theme and graceful
font fallbacks (Times New Roman → Liberation Serif → Nimbus Roman → Tinos).

### Design preview
`preview/home_preview.html` renders the home screen design in a browser
(static mock generated from the live catalog via `packaging/make_preview.py`).
